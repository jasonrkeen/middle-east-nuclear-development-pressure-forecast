# Changelog

All notable changes are documented here. Software releases and forecast issuances are intentionally distinguished.

## 0.2.1 - 2026-08-21

Publication-readiness release; no forecast probabilities changed.

- Added an automated release audit and frozen-registry fingerprint.
- Added contribution, citation, security, and GitHub publication guidance.
- Added structured issue forms for evidence updates, model methodology, and defects.
- Hardened CI with dependency checks and a headless pipeline smoke test.
- Removed duplicated runtime version strings from generated output.

## 0.2.0 - 2026-08-21

Validation and governance release; no forecast probabilities changed.

- Added confidence-weighted evidence updates and an audit output.
- Added source-freshness diagnostics and structural validation cases.
- Froze the v0.1.0 forecast registry for future Brier-score and log-loss evaluation.
- Added model card, validation protocol, baseline comparison, and CI.

## 0.1.0 - 2026-08-21

Initial forecast issuance.

- Published 12-, 24-, and 36-month conditional scenario probabilities.
- Added Monte Carlo uncertainty, regional pressure, sensitivity, economic exposure, charts, and executive brief.
